## 2. 发布探店笔记

### POST `/blog`

发布一篇探店笔记。

**状态：🟢 已实现**

**请求头：** `Authorization: <token>`

**请求体（Blog）：**
```json
{
  "shopId": 4,
  "title": "无尽浪漫的夜晚丨在万花丛中摇晃着红酒杯🍷品战斧牛排🥩",
  "images": "/imgs/blogs/7/14/4771fefb-1a87-4252-816c-9f7ec41ffa4a.jpg,/imgs/blogs/4/10/2f07e3c9-ddce-482d-9ea7-c21450f8d7cd.jpg",
  "content": "生活就是一半烟火·一半诗意<br/>手执烟火谋生活·心怀诗意以谋爱·<br/>..."
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| shopId | Long | 是 | 关联商铺 ID |
| title | String | 是 | 笔记标题（≤255 字符） |
| images | String | 是 | 图片路径（逗号分隔，最多 9 张） |
| content | String | 是 | 笔记正文（≤2048 字符） |

**业务规则：**
1. 从 `UserHolder` 获取当前用户 ID，自动注入 `userId`
2. `liked` 和 `comments` 默认为 0
3. `createTime` / `updateTime` 由数据库自动填充

**成功响应：**
```json
{
  "success": true,
  "errorMsg": null,
  "data": 23,
  "total": null
}
```

> `data` 为新笔记的 ID（Long）。

## 4. 热门笔记列表

### GET `/blog/hot`

按点赞数降序获取热门笔记。

**状态：🟢 已实现（注意：存在 N+1 查询性能问题）**

**请求参数：**

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| current | Integer | 否 | 1 | 当前页码 |

**分页大小：** `MAX_PAGE_SIZE = 10`

**请求示例：**
```
GET /api/blog/hot?current=1
```

**成功响应：**
```json
{
  "success": true,
  "errorMsg": null,
  "data": [
    {
      "id": 4,
      "shopId": 4,
      "userId": 2,
      "name": "可可今天不吃肉",
      "icon": "/imgs/icons/kkjtbcr.jpg",
      "title": "无尽浪漫的夜晚丨...品战斧牛排🥩",
      "images": "/imgs/blogs/7/14/xxx.jpg,...",
      "content": "生活就是一半烟火...",
      "liked": 105,
      "comments": 104,
      "createTime": "2021-12-28T19:50:01"
    }
  ],
  "total": null
}
```

**当前实现的性能问题及优化建议：**

当前代码在循环中对每条 blog 执行 `userService.getById(userId)`，产生 N+1 查询。

```java
// 当前代码（存在 N+1 问题）
records.forEach(blog -> {
    Long userId = blog.getUserId();
    User user = userService.getById(userId);  // 每条 1 次 SQL
    blog.setName(user.getNickName());
    blog.setIcon(user.getIcon());
});
```

**优化方案：**
```java
// 1. 收集所有 userId
List<Long> userIds = records.stream()
    .map(Blog::getUserId).distinct().collect(Collectors.toList());

// 2. 批量查询
Map<Long, User> userMap = userService.listByIds(userIds).stream()
    .collect(Collectors.toMap(User::getId, Function.identity()));

// 3. 填充
records.forEach(blog -> {
    User user = userMap.get(blog.getUserId());
    if (user != null) {
        blog.setName(user.getNickName());
        blog.setIcon(user.getIcon());
    }
});
```

## 6. 关注 Feed 流

### GET `/blog/of/follow`

获取当前用户关注的人发布的笔记，按时间线滚动加载。

**状态：🔴 待实现**

**请求头：** `Authorization: <token>`

**请求参数：**

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| lastId | Long | 否 | — | 上次查询的最后一条笔记 ID（滚动游标） |
| offset | Integer | 否 | 0 | 上次查询的偏移量 |

> 使用 **滚动分页** 而非传统分页，避免数据重复或遗漏。

**业务规则（推模式 — Push）：**
1. 用户发布笔记时，将笔记 ID 推送到所有粉丝的收件箱（Feed 流）
2. 收件箱使用 Redis ZSet：`feed:{userId}` → `{noteId}` score = 时间戳
3. 查询时从当前用户的收件箱按 score 倒序分页拉取
4. 根据 noteId 批量查询 `tb_blog`，再批量填充用户信息

**推模式实现要点：**
```java
// 发送笔记时（saveBlog）：
// 1. 查询当前用户的粉丝列表
List<Follow> fans = followService.query()
    .eq("follow_user_id", userId).list();

// 2. 批量推送到粉丝收件箱
long timestamp = System.currentTimeMillis();
for (Follow fan : fans) {
    String key = RedisConstants.FEED_KEY + fan.getUserId();
    stringRedisTemplate.opsForZSet().add(key, blogId.toString(), timestamp);
}
```

> **注意**：推模式适用于粉丝量较小的场景。若有大 V（百万粉丝），需改用**拉模式**或**推拉结合**。

**成功响应（ScrollResult）：**
```json
{

  "errorMsg": null,
  "data": {
    "list": [
      {
        "id": 23,
        "shopId": 4,
        "userId": 5,

        "icon": "/imgs/icons/user5-icon.png",
        "isLike": false,
        "title": "今日探店分享",
        "images": "...",
        "content": "...",
        "liked": 12,
        "comments": 3,
        "createTime": "2022-01-15T14:30:00"
      }
    ],
    "minTime": 1642252200000,
    "offset": 0
  },
  "total": null
}
```

## 8. 点赞与取消点赞

### PUT `/blog/like/{id}`

给一篇笔记点赞或取消点赞。

**状态：🟡 当前仅实现点赞 +1（无取消、无去重）**

**路径参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| id | Long | 笔记 ID |

**请求头：** `Authorization: <token>`

**当前实现的问题：**
```java
// 问题代码：无去重、无并发控制
blogService.update()
    .setSql("liked = liked + 1")  // 可重复点赞
    .eq("id", id).update();       // 无并发安全
```

**改进方案（使用 Redis Set 去重）：**
```java
// 1. 判断用户是否已点赞
String key = RedisConstants.BLOG_LIKED_KEY + blogId;
Boolean isLiked = stringRedisTemplate.opsForSet().isMember(key, userId.toString());

if (Boolean.TRUE.equals(isLiked)) {
    // 2. 取消点赞
    stringRedisTemplate.opsForSet().remove(key, userId.toString());
    blogService.update().setSql("liked = liked - 1").eq("id", blogId).update();
} else {
    // 3. 点赞
    stringRedisTemplate.opsForSet().add(key, userId.toString());
    blogService.update().setSql("liked = liked + 1").eq("id", blogId).update();
}
```

**成功响应：**
```json
{
  "success": true,
  "errorMsg": null,
  "data": null,
  "total": null
}
```

**改进后可增加返回当前点赞状态：**
```json
{
  "success": true,
  "errorMsg": null,
  "data": {
    "liked": true,
    "likeCount": 106
  },
  "total": null
}
```

## 13. 图片上传

### POST `/upload/blog`

上传探店笔记配图。

**状态：🟢 已实现**

**请求头：** `Authorization: <token>`
**Content-Type：** `multipart/form-data`

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| file | File | 是 | 图片文件（表单字段名 `file`） |

**文件限制建议：**
- 格式：jpg, jpeg, png, gif, webp
- 大小：≤ 5MB
- 数量：单次上传 1 张（多张分批上传）

**存储规则：**
1. 生成 UUID 文件名
2. 根据 UUID 的 hashCode 计算两级哈希目录
3. 目录格式：`/blogs/{d1}/{d2}/`
4. 完整路径：`/blogs/{d1}/{d2}/{uuid}.{suffix}`
5. 上传至 `SystemConstants.IMAGE_UPLOAD_DIR`（`D:\lesson\nginx-1.18.0\html\hmdp\imgs\`）

**请求示例：**
```
POST /api/upload/blog
Content-Type: multipart/form-data

file: [binary image data]
```

**成功响应：**
```json
{
  "success": true,
  "errorMsg": null,
  "data": "/blogs/7/14/4771fefb-1a87-4252-816c-9f7ec41ffa4a.jpg",
  "total": null
}
```

> `data` 为上传后的相对路径，前端可直接用于笔记的 `images` 字段。

### 评论表 (tb_blog_comments)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键，自增 |
| user_id | bigint | 评论用户 ID |
| blog_id | bigint | 关联笔记 ID |
| parent_id | bigint | 父评论 ID（0=一级评论） |
| answer_id | bigint | 被回复的评论 ID |
| content | varchar(255) | 评论内容 |
| liked | int | 点赞数 |

### Redis Key 设计

| Key | 类型 | 说明 |
|-----|------|------|
| `blog:liked:{blogId}` | Set | 笔记点赞用户 ID 集合 |
| `feed:{userId}` | ZSet | 用户收件箱（score=时间戳，member=笔记ID） |
