## 阅读建议

- **新加入的开发者**：先读 [01-通用接口规范](01-通用接口规范.md)，了解统一响应格式和认证机制
- **前端开发者**：重点看各模块的「成功响应」JSON 示例，了解数据结构
- **后端开发者**：关注接口的业务规则、实现要点和优化建议
- **架构评审**：重点关注 [05-§7 秒杀方案设计](05-优惠券模块.md#7-秒杀方案设计)

## 技术债务与已知问题

| # | 问题 | 涉及模块 | 严重程度 |
|---|------|----------|----------|
| 1 | BlogController N+1 查询 | 内容模块 | 中 |
| 2 | 点赞无去重、无并发控制 | 内容模块 | 高 |
| 3 | 商铺查询无缓存 | 商户模块 | 中 |
| 4 | 图片上传路径硬编码 | 内容模块 | 低 |
| 5 | 缺少登录拦截器 | 用户模块 | 高 |
| 6 | 全局异常无业务异常细化 | 通用 | 中 |
